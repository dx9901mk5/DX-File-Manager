Privacy Policy — DX File Manager (DX檔案管理器)

Last updated: 2026-11-16

1. Data Collection & Usage

DX File Manager operates entirely on your local device. When you choose to connect a cloud storage account such as Google Drive, the app requests OAuth 2.0 authorization solely to list, upload, download, copy, move, rename, or delete files that you explicitly manage inside the app.

2. Local Storage of Credentials

Access tokens and mount configurations are stored locally on your device using Android DataStore Preferences and are never transmitted to any third-party server other than the official API endpoints of the cloud service you selected.

3. Google API Services User Data Policy

DX File Manager's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
